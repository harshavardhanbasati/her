# For Rithisha ♡

A responsive, single-page birthday storybook built with React, Vite, Tailwind CSS v4, Framer Motion, and Lucide React.

## Features
- Dreamy cream and blush-pink visual theme
- Responsive single-page layout
- Animated floating petals and scroll reveals
- Illustrated mall-memory scene made with CSS
- Interactive envelope with a birthday letter
- Reduced-motion support and accessible button labels
- No backend, database, or account needed

## Run locally

Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel
1. Push this project to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`

## Customize
- Edit the birthday copy and letter in `src/App.jsx`.
- Adjust colors, layout, and animations in `src/styles.css`.
- The illustrated mall scene is a CSS illustration, so no external image assets are required.
- Google Fonts are loaded remotely; system fallbacks remain available if offline.

## Privacy note
The page is anonymous and static. Avoid adding personal photos or identifying details unless you have permission to share them.
